# MoLaunch 使用基础

MoLaunch 是一个跨平台的 Minecraft 启动器，支持版本管理、模组下载、联机大厅、FRP 穿透等功能。本教程介绍基础使用方法。

## 安装游戏版本

1. 在主页点击「版本管理」
2. 点击「添加版本」按钮
3. 选择游戏版本（如 1.20.1）
4. 可选择安装模组加载器（Fabric / Forge / Quilt / NeoForge）
5. 点击「安装」开始下载

安装完成后，版本列表中会出现新版本，点击即可选中。

## 启动游戏

1. 在主页选择已安装的版本
2. 确认已登录账号（主页右上角显示账号信息）
3. 点击「启动游戏」按钮
4. 等待 Java 启动，游戏窗口自动打开

启动过程中可在日志页查看实时输出。如遇崩溃，启动器会自动分析崩溃原因并给出建议。

## 账号管理

MoLaunch 支持三种账号类型：

- **微软账号**：通过微软 OAuth2 登录，支持正版皮肤和联机
- **外置账号（authlib-injector）**：连接第三方皮肤站服务器
- **离线账号**：无需网络，本地生成 UUID

在主页点击账号头像区域可切换账号或添加新账号。皮肤管理弹窗中可上传/管理皮肤和披风。

## 下载管理

下载页提供资源浏览和下载功能：

- **Mod 下载**：搜索 CurseForge / Modrinth 上的模组
- **整合包下载**：浏览和安装整合包
- **资源包/光影**：下载视觉资源

下载任务支持暂停、取消和断点续传。下载完成后自动安装到当前选中版本。

## 联机功能

联机功能让玩家通过 P2P 或中继建立 Minecraft 多人连接：

1. **设备注册**：首次使用联机功能需注册设备（自动完成）
2. **创建房间**：房主创建房间，设置房间名和密码
3. **邀请加入**：分享房间码给好友
4. **大厅浏览**：在联机大厅浏览公开房间

联机使用 WebRTC 建立连接，NAT 穿透失败时自动切换到 TURN 中继。

## FRP 穿透管理

FRP 管理位于联机页面侧边栏，提供：

- **厂商列表**：管理 FRP 厂商（内置系统默认厂商 + 外部厂商安装）
- **穿透管理**：创建和管理 FRP 隧道
- **认证中心**：管理厂商认证（OAuth2 / Device Code / API Key）
- **运行日志**：查看 frpc 运行日志

如需开发自定义 FRP 厂商，请参阅「FRP 厂商开发指南」教程。

## 工具箱

工具箱页面提供实用工具：

- **存档管理**：备份、导出、导入存档
- **种子地图**：使用 Cubiomes 生成种子地图，支持从存档提取种子
- **缓存监控**：查看和管理缓存空间

## 设置概览

设置页面提供以下分类：

- **启动**：Java 路径、内存分配、JVM 参数
- **下载**：下载源、并发数、下载目录
- **个性化**：主题色、背景图片、主页布局
- **插件**：管理已安装插件
- **高级**：调试模式、日志级别、数据目录
- **联机**：api-server 地址、设备管理
- **缓存**：缓存清理、空间管理
- **更多**：关于、系统信息、鸣谢、教程
