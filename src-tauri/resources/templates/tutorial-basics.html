MoLaunch 使用指南

欢迎使用 MoLaunch！这是一款跨平台的 Minecraft 启动器，支持版本管理、模组下载、联机大厅、FRP 穿透等功能。本指南从玩家视角出发，带你逐步掌握全部功能。

一、快速开始（5 分钟上手）

  1. 登录账号：启动后进入登录页，可选择「离线登录」「微软登录」「外置登录」三种方式之一（详见第二章）。
  2. 安装游戏版本：进入主页 → 点击版本选择器 → 若无版本则点「下载游戏」→ 选择 Minecraft 版本 → 选择加载器（或直接安装原版）→ 点「开始安装」。
  3. 选中版本：安装完成后回到版本选择页，点击刚安装的版本。
  4. 启动游戏：回到主页，确认账号与版本无误，点击「启动游戏」按钮。首次启动会自动检测或下载所需 Java，耐心等待即可。

就这么简单！后续章节将逐一详解每个功能的完整用法。

二、账号登录

MoLaunch 支持三种账号类型，登录页顶部三个标签页可切换：

2.1 离线登录

  1. 切换到「离线登录」标签。
  2. 输入用户名（最多 16 个字符，仅限字母、数字、下划线），回车或点「离线登录」。
  3. 登录成功自动跳回主页。
离线模式仅能进入支持离线登录的服务器；账号会保存在本地，之后可在主页直接切换。

2.2 微软登录（正版）

  1. 切换到「微软登录」标签，点「微软账号登录」。
  2. 弹出设备码弹窗：设备码已自动复制到剪贴板，约 2 秒后自动打开 Microsoft 授权网页。
  3. 在网页登录并输入设备码完成授权（若网页未自动打开，可点弹窗内「打开 Microsoft 登录页」）。
  4. 回到弹窗等待，后台自动完成 XBL → XSTS → Minecraft Token → 所有权验证 → 玩家档案等步骤，成功后回到主页。
Token 过期时启动器会静默自动刷新；授权失败时可按提示「重新登录」。

2.3 外置登录（authlib-injector / yggdrasil，如 LittleSkin）

  1. 切换到「外置登录」标签。
  2. 输入服务器地址（只需输入域名如 littleskin.cn，失焦或点「获取」会自动补全为完整接口地址）。
  3. 获取成功后显示服务器名与「注册账号」链接。
  4. 输入账号（邮箱或用户名）+ 密码，点「外置登录」；若账号有多个游戏角色，会弹窗选择。

2.4 主页账号区

  • 顶部胶囊显示账号状态：蓝色=正版、紫色=外置、灰色=离线、绿色=游戏运行中。
  • 已登录时卡片可左右箭头 / 拖动 / 滚轮切换多账号；点击卡片切换当前账号。
  • 卡片按钮：「皮肤」打开皮肤管理弹窗（上传/管理皮肤与披风，离线账号可选本地默认皮肤）；「登出/删除」退出当前账号或删除其他账号。
  • 卡片列表末尾虚线「添加账号」卡，点击进入登录页添加新账号。

三、主页与启动游戏

3.1 主页布局

主页左右双栏：左侧固定启动面板（账号区 + 版本选择 + 启动按钮），右侧为内容区（启动时显示进度，平时显示时钟卡片、插件面板或自定义布局）。

3.2 启动按钮的 5 种状态

  • 未登录：「登录后可启动」（灰色禁用）
  • 启动中：「取消启动」（黄色，可取消）
  • 游戏运行中：「停止游戏」（红色，可结束游戏进程）
  • 未选版本：「选择版本」（灰色禁用）
  • 正常：「启动游戏」（主题色）

3.3 启动过程

点击启动后右侧切换为启动日志视图，展示全局进度条，阶段依次为：初始化 → 获取 Java → 登录验证 → 文件检查 → 构建参数 → 启动前命令 → 解压原生库 → 启动进程 → 等待窗口 → 完成。若本机缺少所需 Java，会自动下载。游戏退出时：正常退出提示「游戏已退出」；异常退出自动弹出崩溃分析对话框。

3.4 主页右侧面板模式

默认显示时钟卡片（大时钟 + 底部每 6 秒轮播内存/版本数/缓存等信息）。可在「设置 → 个性化 → 主页」切换为：默认 / 插件模式（使用插件提供的主页组件）/ 自定义模式（JSON / XML / HTML 布局，支持内联编辑或 URL 远程加载）。

四、安装游戏版本

  1. 进入下载页（主页版本选择器内点「下载游戏」，或左侧导航「下载」）。
  2. 左侧选「原版游戏」，右侧按分组展示版本：最新版本 / 正式版 / 快照版 / 愚人节版 / 远古版，点击分组可折叠。
  3. 点版本行右侧「安装」，滑入「选择加载器」页。
  4. 选择加载器卡片：Forge（经典，生态最丰富）/ NeoForge（Forge 社区分支，适配新版）/ Fabric（轻量，适合客户端/性能优化 Mod）/ OptiFine（性能优化与光影，可与其他共存）/ LiteLoader（轻量，1.12.2 后停更）。不选任何加载器 = 安装原版。
  5. 确认版本名（默认自动生成如 1.20.1-Fabric0.15.11，可自定义），点「开始安装」。
快照版建议选 Fabric；愚人节版不支持加载器；远古版兼容性差。安装为后台执行，进度在右下角下载面板展示，完成后有提示。

五、版本管理与版本设置

5.1 版本选择页

  • 左侧文件夹列表：列出所有已添加的 Minecraft 文件夹，点击切换；hover 显示完整路径。
  • 「添加已有文件夹」：选择 .minecraft 目录并命名。
  • 「导入整合包」：选择本地 .zip / .mrpack 文件走整合包导入流程。
  • 右侧版本列表按类型分组（正式版/快照/整合包/Mod 版等），点击版本即选中并返回主页；选中版本会记住，下次启动自动恢复。

5.2 版本设置页

入口：主页「版本设置」按钮。顶部显示「版本设置 - 版本名」，左侧共 6 个标签页：

概览

  • 版本展示卡：图标 + 版本名 + 类型 + 收藏星标。
  • 个性化：重命名、修改描述、更换图标、设置分类。
  • 快捷方式：一键打开版本 / 存档 / Mod / 材质包 / 光影文件夹。
  • 高级管理：导出启动脚本、补全文件（校验并下载缺失文件）、检测并重装加载器（自动扫描是否损坏并可一键重装）、删除版本（不可撤销）。

设置

  • 版本隔离：跟随全局 / 开启（存档 Mod 独立）/ 关闭（共享存档 Mod）。
  • 游戏窗口标题（留空跟随全局）、自定义信息（显示在游戏主界面左下角，新版 MC 已移除该设置）。
  • 游戏 Java：4 种模式（详见第七章）。
  • 内存分配：跟随全局 / 自动配置（按可用内存 75%，上限 8GB）/ 自定义滑块（最大 512MB~16GB、最小 256MB 起）。
  • 服务器：自动进入服务器，格式 IP:端口。
  • 进阶开关：禁止更新 Mod、忽略 Java 兼容性警告、关闭文件校验、禁用 Java Launch Wrapper（JLW）、禁用 LWJGL Unsafe Agent（LUA）。

Mod 管理

  • 工具栏：从文件安装（本地 jar）/ 打开文件夹 / 刷新；筛选（全部/已启用/已禁用）；搜索。
  • 列表项：启用/禁用开关、删除、查看详情、打开 Wiki、打开本地文件、更新/更改版本。
  • 多选批量操作：点击选中、Shift 范围选择、ESC 清空；底部浮动操作栏可批量启用/禁用/更新/删除。

资源包 / 光影

与 Mod 管理布局一致：从文件安装（zip）/ 打开文件夹 / 刷新 / 筛选 / 搜索，支持启用、删除、查看详情、更新版本。

导出

  • 基本信息：导出格式（Modrinth 等）、整合包名称、整合包版本。
  • 联网检查：勾选后联网查询 Mod 下载地址（Modrinth + CurseForge）；「仅 Modrinth」跳过 CurseForge。
  • 导出选项：勾选式选项列表（父子层级，必选项不可取消），可读取/保存配置复用。
  • 点「导出整合包」，完成后到保存位置查看。

六、下载与社区资源

6.1 下载 Mod / 资源包 / 光影 / 数据包

  1. 下载页左侧选「社区资源」分类（Mod / 整合包 / 资源包 / 光影 / 数据包）。
  2. 第一行：输入关键词（输入即自动搜索，下拉有搜索历史）；「来源」可选全部 / 仅 CurseForge（CF 橙色标签）/ 仅 Modrinth（MR 绿色标签）。
  3. 第二行筛选：游戏版本（可输入或下拉）、加载器（Forge / NeoForge / Fabric / Quilt / LiteLoader）、分类。
  4. 点击结果卡片打开详情弹窗：查看简介、版本列表、文件大小；点某版本「下载」→ 系统保存对话框选位置（文件名按设置自动生成）→ 开始下载。

前置依赖（仅 Mod）

在版本管理场景进入详情并下载时，会先检查缺失前置：发现缺失弹出「发现 N 个缺失前置」确认窗，可勾选要一并安装的前置；下载页场景直接下载不检查。

6.2 下载任务管理

  • 有下载任务时，右下角出现圆形下载按钮（外圈进度环），点击进入下载管理页。
  • 左侧统计：当前阶段、总进度、速度、已下/总量、剩余文件数。
  • 右侧任务卡片：每任务组可折叠展开；点「暂停/恢复」随时控制（支持断点续传），点「取消」终止任务（已下载文件保留）。
  • 下载完成 / 取消 / 失败确认后自动返回原页面。

6.3 外部下载（URL 下载任意文件）

  1. 工具页 →「下载管理」→ 输入下载地址（必须 http/https 开头）→ 自动获取文件名（可手动改）→「开始下载」。
  2. 支持暂停/恢复/取消、断点续传、多线程分片下载。
  3. 高级设置（折叠面板）：自定义 User-Agent、并发线程数、单文件分片数、限速，应对部分资源站限速/防盗链。
  4. 「已下载文件」列表可管理下载目录内文件，支持删除、选择目录、打开目录。

    5. 6.4 拖拽安装（全局）

    • 拖入 .zip / .mrpack → 整合包安装（预览格式 → 输入实例名 → 可选 Mod 询问 → 自动安装）。
    • 拖入 .jar / .litemod 等 → Mod 安装（选择目标版本）。
    • .rar 会被拒绝（先解压再压缩为 zip）。

    6.5 下载源配置

    设置 →「下载配置」：版本列表源与文件下载源均支持「官方源 / BMCLAPI / 优先官方」；并行下载数 1~16（推荐 8）、下载线程数 1~8（推荐 4）、下载限速滑块（拖动到「不限」即不限速）。

    设置 →「进阶设置」→ 社区资源：来源三档「尽量镜像 / 缓慢时换镜像 / 尽量官方」（镜像源可能缺少刚更新的版本，遇到整合包/批量下载问题请切到后两档）；文件名格式 5 种；Mod 管理样式；忽略 Quilt 加载器。

    七、Java 环境管理

    • 自动检测：启动时自动扫描系统已装 Java。
    • 自动下载：启动时发现无兼容 Java，自动下载所需版本并继续启动。
    • 版本级 Java：版本设置 → 设置 → 游戏 Java，4 种模式：自动选择（推荐，按版本兼容性自动选）/ 自动选择指定版本（输入主版本范围，0=不限）/ 使用版本文件夹中的 Java / 使用指定的 Java（下拉选择或手动导入 javaw.exe，不兼容时红色警告）。
    • 工具页 → Java 诊断：Java 下载器（预设 Java 25/21/17/16/8 档位 + 自定义）、环境检测（逐版本判断 Java 是否满足需求并可一键预下载）、运行时列表。

    八、联机功能

    入口：左侧导航「联机」。首次使用会弹联机协议，同意后进入。顶部徽章：云端离线（红）/ 已就绪（绿）/ 未注册（灰）/ 需登录（黄）。设备注册为无感自动完成。

    8.1 设备面板

    • 网络环境：自动检测 NAT 类型（公网直连 / 全锥 / 限制锥 / 端口限制锥 / 对称 / UDP 阻断 / 检测失败），可刷新；「网络拓扑」力导向图可复制分享给朋友判断联机可能性。
    • 虚拟组网（easytier）：组网状态、core 版本、虚拟网络名、虚拟 IP。
    • 设备信息：设备 ID、api-server 地址、JWT 过期时间。

    8.2 联机大厅

    按整合包聚类展示公开房间（热度排序），展开后可见房间码、加载器、MC 版本、人数、密码锁标记；点「加入」→ 无密码直接进房，有密码输入后自动组网并探测进服地址。

    8.3 创建房间（搭桥联机）

    1. 联机页 → 搭桥联机 → 创建房间。先确认游戏中已开启「对局域网开放」。
    2. 填写：MC 版本（自动解析加载器）、MC 端口（默认 25565，可「选择端口」）、房间备注（选填）、房间类型（公开/私密）、房间密码（选填）。
    3. 高级设置可「关联整合包」，加入方据此校验或一键安装。
    4. 点「创建房间」，三步完成：生成房间码 → 登记房间 → 拉起联机中心。

    创建成功后：房间码（默认 6 位 N 段码，点击切换完整 U/xxx 码并复制）、连接状态卡（组网设备列表 5 秒刷新）、MC 端口卡（自动探测，可手动指定）；「房间工具」抽屉含检查 MC 服务（SLP 协议）、端口自动检测；「关闭房间」按钮停服。

    端口变更后非 MoLaunch 玩家需重新加入房间；后端监视到 MC 服务 30 秒不可达会自动关房。

    8.4 加入房间（搭桥联机）

    1. 联机页 → 搭桥联机 → 加入房间。输入房间码（支持陶瓦联机、PCL 等兼容启动器的码）+ 密码（无密码留空），点「加入房间」。
    2. 进房后：房间信息卡、整合包要求卡（已安装=绿 / 需安装=蓝，可一键安装 / 不可安装=红）、连接状态卡。
    3. 进服地址卡：显示 127.0.0.1:本地转发端口，点「复制」→ 在游戏「多人游戏 → 直接连接」粘贴进入房主房间。
    房主端口变更时进服地址每 5 秒自动轮询更新；房主关房时自动提示并退出；若显示「尚未探测到房主 MC 服务」，请确认房主已开「对局域网开放」。

    8.5 红石联机（独立隧道）

    1. 联机页 → 红石联机 → 创建房间。选中转服务器（从红石官网实时拉取列表，可测延迟/刷新，也可手动填写）。
    2. 填写本地 MC 服务端口（默认 25565），点「创建隧道」→ 生成联机地址 → 「复制地址」发给好友直连进服。
    3. 「内核状态」页可查看运行状态与内核日志。隧道 10 人上限 / 10Mbps；无玩家 10 分钟或运行满 6 小时自动关闭。

    8.6 FRP 联机（内网穿透）

    子菜单：厂商列表（浏览/安装/管理 FRP 厂商，从文件夹/ZIP/URL 安装）、穿透管理（创建/启动/停止隧道）、认证中心（OAuth2 / Device Code / API Key 认证）、运行日志、教程帮助。不依赖 MoLaunch 云端，即使云端离线也可使用。

    8.7 局域网发现

    房主房间会向局域网广播，游戏「多人游戏」界面可直接发现房主房间，无需输入地址。

    九、工具页

    入口：左侧导航「工具」。共 7 大分类：

    9.1 下载管理

    见第六章 6.3 外部下载。

    9.2 常用工具

    • 今日人品：基于设备 ID + 日期哈希的每日幸运值（0-100），等级欧皇/小欧/普通人/非酋/大非酋，纯本地娱乐。
    • 便捷工具：
      • 清理游戏垃圾：扫描 .minecraft 下日志/崩溃报告等，按全局/各版本分组勾选后清理。
      • 内存优化：轻量（清空进程工作集）/ 强力（额外清空待机内存，需确认）。
    • 坐标计算：两组 XYZ 坐标计算欧氏/曼哈顿/切比雪夫距离 + 地狱门 1:8 换算。
    • 调色板：RGB/HEX/HSL 互转 + Minecraft § 颜色代码 + 16 种染料色板。
    • 版本 JSON：编辑已安装版本的 JSON 文件（误改可能导致无法启动）。
    • 皮肤下载：输入正版玩家名获取 UUID/皮肤/披风，3D 预览，可保存到本地。

    9.3 数据迁移

    自动扫描 PCL2 / PCL2CE / HMCL / MultiMC / Prism Launcher / CurseForge 实例，勾选导入，模式可选「复制」或「符号链接」（共享数据省空间）。

    9.4 存档资源

    • 存档管理：列出存档（支持版本隔离），可备份（弹窗选 zip 输出路径，可排除玩家数据）、从 zip 恢复（可自定义恢复后名称）。
    • NBT 编辑器：打开 .dat / .nbt / .mca 文件（或从存档选择），树形编辑节点；.mca 可切换区块。
    • 截图管理：列截图目录，多选/全选批量删除（显示释放空间）。
    • 资源包转换、资源包编辑器：打开资源包（目录/ZIP/文件夹），编辑 mcmeta、纹理 2D 预览替换、语言表格、JSON 文本、声音试听；保存回原包或另存 ZIP。
    • 种子地图：输入种子 + 版本/维度 → 渲染地图；「从存档」读种子；拖拽/缩放/点击结构查询。仍在测试中，不保证准确率。

    9.5 Mod 网络

    • 依赖检测：扫描 mods 目录依赖声明，列出缺失依赖。
    • Mod 去重：找出同 mod_id 多版本的重复文件。
    • 服务器检测：SLP 协议查询服务器 MOTD/在线人数/版本/延迟。
    • 延迟测试：并发测 URL 延迟，提供官方源/BMCLAPI 预设。
    • 地址测速：TCP 握手 / UDP 探针 / Ping 三种协议测速。

    9.6 Java 诊断

    见第七章。

    9.7 创作指令

    • 渐变文字：多行文本 + 颜色停靠点，实时预览，生成 19 种输出格式（Vanilla/MiniMessage/JSON/BBCode 等），预设管理。
    • 合成配方：选版本与配方类型，点击格子填物品/标签，导出数据包。
    • 物品编辑（/give）：搜索物品、数量、目标、指令版本、自定义名称/Lore/附魔。
    • 告示牌商店（/setblock）：类型/朝向/坐标/4 行文字/颜色。
    • 召唤实体（/summon）：实体/坐标/数量/名称。
    • 成就生成器：Canvas 绘制原版风格「获得成就！」弹窗，导出 PNG。

    十一、实验性功能

    入口：设置 → 进阶设置开启「实验性功能」后，顶部导航出现「实验性」；进入时每日弹使用协议。左侧分类：AI 聊天 / 日志分析 / 模组翻译 / AI 设置。

    • AI 聊天：本地 AI 对话（会话 SQLite 持久化），支持模型选择、推理开关、附件（崩溃日志/游戏日志/Mods 列表）、流式输出、Agent 工具。
    • 日志分析：粘贴日志 → 本地引擎识别常见崩溃（Java 版本/缺失 Mod/内存/显卡驱动/Mod 冲突等）→ 可「用 AI 深度分析」（只上传关键词附近上下文，日志全文不上传）。
    • 模组翻译：拖入 Mod JAR → 分析语言文件 → 设置翻译模型/批次 → 开始翻译；覆盖已有中文语言文件前会二次确认（AI 翻译准确率有限，建议优先用 i18n 翻译模组）。

    十二、常见问题与排障

    • 游戏无法启动 / 缺文件：版本设置 → 概览 →「补全文件」。
    • 加载器损坏：版本设置 → 概览 →「检测并重装加载器」。
    • 游戏崩溃：启动器自动弹出崩溃分析；也可用「实验性 → 日志分析」粘贴日志。
    • 中文路径启动失败：确认 JLW 未禁用；或关闭「禁用 Java Launch Wrapper」。
    • 游戏卡顿：确认 LUA 未禁用；Java 使用独立显卡（笔记本双显卡）；调大内存。
    • 下载慢：切换下载源（BMCLAPI/优先官方）、调大并行数/线程数、检查限速。
    • 镜像源下载异常：设置 → 进阶设置 → 社区资源，切到「缓慢时换镜像」或「尽量官方」。
    • 下载被限速/防盗链：外部下载高级设置自定义 User-Agent。

    十三、开发者模式（进阶玩家）

    1. 解锁隐藏入口：设置 → 更多 → 鸣谢 → 法律信息 → 版权声明中「MoTeam」字段，3 秒内连续点击 7 次（成功后会有提示）。
    2. 到「进阶设置」打开「开发者模式」开关，侧边菜单末尾出现「开发者」分类。

    开发者分类内含：实验性功能（Modrinth CDN 直连、更新检测分支）、DevTools（打开/关闭 WebView2 调试工具）、证书与安全（TLS 信任源、忽略证书校验、自定义证书管理）、日志（HTTP 请求日志、运行日志）、存储（各缓存与数据目录定位）、系统信息、深链接（molaunch:// 协议注册管理）、IPC 调试器（直接调用后端命令，含危险操作，谨慎使用）、启动参数预览（按当前配置组装最终启动参数，不启动游戏）。

    快捷键：Ctrl/Cmd + Shift + D 切换 DevTools；Alt + 1~9 切换开发者子页签。
