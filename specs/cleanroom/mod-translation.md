# 规格：AI 模组翻译

依据：JVMS《Java Virtual Machine Specification》第 4 章（class 文件格式）、ZIP 容器格式、
Minecraft 资源包语言文件格式、通用文本占位符约定。目标：把一个模组 JAR 里的英文文本
翻成中文，并重新打包成可直接替换的 JAR。

## 1. 安全解包

输入：一个 JAR/ZIP 文件。解包到任务工作区，必须满足：

| 限制 | 值 |
|---|---|
| 归档大小 | ≤ 1.2 GB |
| 条目数 | ≤ 200000 |
| 单条目解压后 | ≤ 256 MB |
| 全部条目解压后 | ≤ 2 GB |
| 单条目压缩比 | ≤ 200 |

另外：拒绝绝对路径、含 `..` 的路径、盘符前缀、NUL 字节；拒绝符号链接；遇到 `META-INF/*.SF|RSA|DSA|EC` 记为「已签名」，重打包后签名失效需提示。

工作区按归档内相对路径镜像；额外写一份元数据（格式版本、是否签名、条目数），元数据与内部临时文件不写入输出 JAR。

## 2. 语言源识别

在 `assets/<namespace>/lang/` 下识别：

| 文件 | 解析方式 |
|---|---|
| `*.json` | JSON 对象，键值均为字符串 |
| `*.lang` | 每行 `key=value`，忽略空行与 `#` 注释 |
| `*.properties` | 同 `.lang` |

只处理英文源（`en_us` 等）；已存在目标语言文件时并入而非覆盖。

## 3. class 字符串提取

1. 校验魔数 `0xCAFEBABE`。
2. 读常量池：tag 1 = UTF8（长度前缀 + 字节），tag 8 = String（指向 UTF8 槽位）；tag 5/6（LONG/DOUBLE）占两个槽位；其余 tag 按固定长度跳过（3/4→4 字节，7/16/19/20→2 字节，9/10/11/12/17/18→4 字节，15→3 字节）。
3. 只取被 String 常量引用的 UTF8 文本（运行时字符串）。
4. 候选判定（按顺序）：
   - 含中文 → 已本地化，跳过
   - 长度 <3 或 >500、无 ASCII 字母、含 NUL → 无效
   - 去掉 `§x` 颜色码后只剩占位符骨架（`%s`、`{0}`、`<tag>` 且无实词）→ 格式骨架
   - 全大写+数字+下划线 → 常量名
   - 形如 JVM 描述符（`Lfoo/Bar;`、`(I)V`、`[B`）→ 描述符
   - 形如 URL / Windows 路径 / Unix 路径 / 命名空间路径 / 纯小写标识符 → 结构性字符串
   - 形如 `/command args` → 纯命令
   - 形如单个首字母大写的词 → 展示用单词（候选）
   - 含空格或标点 → 自然语言（候选）
   - 其余 → 结构性，跳过
5. 跨文件聚合：同一文本出现在多个 class 时合并为一个候选，记录全部出现路径；候选 id = sha256(首个路径 + NUL + 文本) 前 24 位十六进制。
6. 确定性排除：Java 全限定类名、正则表达式、以及「诊断类宿主路径 + 诊断文案」组合（`IOException`、`failed to`、`retrying`、`unknown status`）；GUI/提示类宿主路径不排除。

## 4. 改写

- 只重建被替换的 UTF8 常量区间（tag + 长度 + 内容），其余字节原样拷贝。
- 替换文本 UTF-8 长度不得超过 65535。
- 同一文本出现在多个常量池条目时全部替换。

## 5. 翻译流程

1. **分析**：统计语言源、候选文本、条目数，产出检查结果（语言源列表、条目总数、class 候选数、警告）。
2. **路由**：语言文件与 class 文本分别走不同翻译路径（语言文件按 key 批量，class 按候选批量）。
3. **翻译**：调用 AI，要求保留占位符（`%s`、`{0}`、`§` 颜色码、`\n`）与术语一致；失败重试，仍失败则记录为「未解决」。
4. **校验**：占位符集合必须与原文本一致，否则判为不合格并重试。
5. **落盘**：语言文件按 key 写回；class 按候选改写字节。
6. **重打包**：输出同目录 `<原名>-zh_cn.jar`；已存在则拒绝覆盖。
7. **断点续传**：工作区写续传标记（输入文件哈希 + 身份 + 检查点），命中相同哈希时复用已完成的批次。

## 6. 报告

任务结束时产出：输出路径、模组名、语言条目尝试/通过数、class 解决数/总数、警告列表。

## 7. 验收用例

1. 常量池：UTF8 条目按槽位顺序返回，区间正好覆盖 tag+长度+内容。
2. 只返回被 String 引用的文本。
3. LONG/DOUBLE 双槽位不破坏后续解析。
4. 非 class 输入、截断输入、未知 tag 均返回错误。
5. 改写只动目标条目，其余字节一致；未命中时返回原字节；超长替换报错。
6. 跨文件聚合：同一文本两个文件 → 1 个候选、出现 2 次。
7. 确定性排除：Java 类名、正则、诊断文案被排除，GUI 文案保留。
8. 解包：越界路径、符号链接、超大条目、异常压缩比均被拒绝。
9. 打包：遍历工作区还原条目名，内部文件不进入输出。
